Emergency Locksmith Information Service

What is klygo?

klygo is an informational ChatGPT app that helps users understand their door lock situation when they're locked out. The app provides guidance on lock types, estimated difficulty, general cost ranges, and safety tips.

Important: This app is purely informational. It does NOT provide:
  • Locksmith booking or dispatch
  • Payment processing
  • Direct connections to service providers
  • Precise location requests

Available Tools (MCP)

The app provides three read-only tools for information gathering:

assess_situation

Evaluates the user's lockout situation and determines if professional help is needed.

Read-Only

analyze_lock

Analyzes lock type from description/photo and provides difficulty assessment.

Read-Only

get_recommendation

Provides general guidance, cost ranges, and safety tips based on the situation.

Read-Only

App Assesses the Situation

Using the assess_situation tool, the app evaluates whether DIY solutions are possible or if professional help is recommended.

상황 평가 결과:

• 도어락 종류: 디지털 도어락 (푸시풀 타입 추정)
• DIY 가능성: 낮음
• 권장 조치: 전문 기사 호출 권장

배터리 교체 후에도 작동하지 않는다면 내부 기판 문제이거나 잠금 메커니즘 고장일 수 있습니다.
3

App Analyzes the Lock Type

Using the analyze_lock tool, the app provides information about the lock type and expected difficulty.

도어락 분석:

• 예상 종류: 푸시풀 디지털 도어락
• 작업 난이도: 중간~높음
• 비파괴 개문 가능성: 상황에 따라 다름

⚠️ 참고: 정확한 분석을 위해서는 현장 확인이 필요합니다.
