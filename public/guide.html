안전 가이드

🚨 긴급 상황 시

  • 화재, 가스 누출 등 안전 위험 시 119 먼저 연락
  • 아이/노약자가 갇힌 경우 소방서 출동 요청
  • 범죄 의심 시 112 신고

📋 기사 방문 전 준비사항

  • 신분증 준비 (주민등록증, 운전면허증)
  • 거주 증빙 (임대차계약서, 등기부등본) - 필요시
  • 관리사무소/경비실에 미리 알려두기
  • 공동현관 비밀번호/출입 방법 확인

💳 견적 확인 체크리스트

  • 출장비 금액 확인
  • 작업비 예상 범위 확인
  • 추가비 항목 확인 (야간, 파손, 거리 등)
  • 결제 방법 확인 (현금/카드)
  • 영수증 발급 가능 여부

✅ 바가지 방지 팁

  • 전화로 대략적인 비용 범위 먼저 문의
  • 작업 전 견적서를 문자/카톡으로 요청
  • 작업 후 영수증 필수 수령
  • 불합리한 요금은 소비자원(1372) 신고
  • 후기/리뷰 확인 후 업체 선택

🔧 DIY 시도 전 주의사항

  • 무리한 시도 시 도어락 파손 위험
  • 파손 시 수리비가 더 많이 들 수 있음
  • 관리사무소 마스터키 먼저 확인
  • 가족/동거인 여분 열쇠 확인
